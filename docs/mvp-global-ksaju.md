# MVP Spec — Global (English) K-Saju AI

> 확정 제품. 상위 결정 맥락은 [product-direction.md](./product-direction.md) 참고.
> 작성: 2026-06-17. 솔로 빌더 / B2C / 프리미엄.

## 한 줄

영어권 Gen Z를 위한 **대화형 AI K-사주** — 묻고 답하고, 따뜻하게 풀어 설명하고,
공유되는 감성 차트로 바이럴되는 운세 앱.

## 왜 이긴다 (정량 근거)

- **수요 검증**: 사주가 TikTok에서 Gen Z 글로벌 바이럴("Four Pillars" 차트, "SJPJ=한국판 MBTI").
  결정적 신호 — 사람들이 **이미 ChatGPT에 프롬프트 붙여넣어 사주 리딩을 받고 있다**
  (바이럴 영상이 프롬프트를 공유). = 미충족 수요가 범용 툴에 갇혀 있음.
- **시장 돈**: 점성술 앱 시장 $4.73B(2025)→$5.69B(2026). 결제 의향 입증(CheokCheok $5.99~,
  Etsy 8페이지 리딩, 1:1 상담).
- **경쟁 빈틈 (Co-Star 2천만 다운로드의 검증된 약점 — LLM이 전부 native하게 해결)**:
  1. **후속 질문 불가** ("목요일 면접에 이게 무슨 뜻?" 물어볼 수 없음) → 우리는 대화형.
  2. **용어 설명 없음 / 모호함** → 우리는 풀어 설명(직역 아닌 문화적 해석).
  3. **차갑고 "괴롭히는" 톤, 불안 유발** → 우리는 따뜻·격려 톤(명시적 설계).
- **차별점 vs 기존 K-사주 앱**: K-Saju Guide(MWM, 205K+ 다운로드, 4.2★, AI 어시 SAVIS 보유)가
  현재 최강자. 정면 "또 하나의 AI 사주"로는 못 이김 → **톤 + 진짜 대화 + 바이럴 공유 루프 + 연애·궁합**으로 차별화.

## 경쟁 지형 (요약)

| 구분 | 대표 | 강점 | 빈틈(우리 기회) |
|---|---|---|---|
| 서구 별자리 | Co-Star(2천만), Sanctuary, The Pattern | 거대 사용자·브랜드 | 사주 아님, 비대화·모호·차가움 |
| 영어 K-사주 | **K-Saju Guide(205K,4.2★,AI)**, Sajuping, Saju World, CheokCheok | 사주 정통, 일부 AI | 톤·대화 깊이·바이럴 약함, 신생 다수 |
| 중국 BaZi | Bazi Fortune(10개국어), OpenFate AI | 같은 사주 시스템·성숙 | **K-컬처/K-브랜딩 없음** ← 우리 차별 |
| 범용 | **ChatGPT 프롬프트 복붙** | 무료·강력 | 제품 아님(매번 복붙, 차트계산 부정확, 저장·공유·리텐션 없음) |

## 핵심 기능 (MVP, 솔로 4주)

1. **온보딩 → 차트 계산**: 생년월일·시·출생지·성별 → 사주 4기둥 + Day Master + 오행 밸런스.
   - 엔진: 오픈소스 **manseryeok(TS)** 또는 BaZi 라이브러리. true solar time/만세력 정확도 필수(신뢰의 핵심).
2. **즉시 "와우" 무료 리딩**: Day Master 아키타입 리포트(성격) + **공유용 감성 카드**
   ("I'm Yang Wood 甲木 — the new MBTI"). = 바이럴 훅 + 가치 즉시 입증.
3. **대화형 챗**: 차트에 grounding된 LLM에게 연애·커리어·올해운 무엇이든 질문·후속질문.
   (Co-Star가 못 하는 바로 그것.)
4. **데일리 운세 푸시**: 매일 재방문 = 리텐션 = 구독 정당화.
5. **궁합(Compatibility)**: 상대(연인/크러시) 정보 추가 → 궁합 리딩. **공유 + 초대 루프**(성장 엔진) + 결제의향 높음.

## 수익 모델 (Freemium)

- **무료**: 차트 + Day Master 아키타입 카드 + 데일리 1개 + 챗 **3질문/일** 맛보기.
- **구독(~$6–9/월)**: 무제한 챗, 풀 라이프 리포트(커리어·재물·건강·10년 대운 흐름), 궁합 무제한, 연간 운세, 심화 데일리.
- **단건 IAP**: 궁합 리포트 / 연간 리포트 단건 언락(충동구매·비구독자 수익화).

## 바이럴 훅 (3)

1. **Day Master 아키타입 카드** — TikTok/IG 공유되는 감성 이미지("한국판 MBTI" 프레이밍).
2. **궁합 초대 루프** — 상대를 초대해야 결과 완성 → 자연 성장.
3. **"ChatGPT 프롬프트를 이긴다"** 포지셔닝 — 복붙하던 사람들에게 진짜 제품(정확한 차트+저장+공유+대화).

## 기술 스택 / 비용 (솔로 현실)

- **앱: Flutter/Dart** (주인 주력 스택 — lingua-journal, vloglet, malgil, filmlovers 모두 Dart).
- **사주 계산**: 오픈소스 결정론적 엔진(무료, 서버/온디바이스). 차트는 캐시.
- **LLM**: 최신 Claude. 비용 설계 — 심화 리포트는 고성능 모델, 데일리·일반 챗은 경량 모델, 베이스 해석은 캐시해 토큰 절감. 무료 티어는 챗 횟수 캡으로 비용 방어.
- **결제**: RevenueCat + 스토어 IAP/구독.

## 리스크 & 대응

- **K-Saju Guide 선점(205K, AI 보유)** → 정면승부 금지. 톤·대화·바이럴·궁합으로 측면 공략. 초기 타겟: TikTok에서 사주 보는 영어권 Gen Z 여성.
- **수요 초기성 (영어 사주 다운로드 대부분 월 <100, 바이럴≠결제)** → 유료 마케팅 대신 **TikTok 오가닉 + 공유 루프**로 CAC 낮게. 빠르게 결제 전환율 측정 후 판단.
- **차트 정확도** = 신뢰 생명선 → 검증된 만세력/true solar time 엔진, 출시 전 한국 앱과 교차검증.
- **LLM 비용** → 캐시 + 무료 캡 + 경량 모델 라우팅.
- **스토어 정책** → "엔터테인먼트" 디스클레이머, 의학/재무 단정 회피.

## 다음 단계 (next agent / 빌드 착수)

1. 사주 계산 엔진 후보(manseryeok TS vs BaZi libs) 정확도·라이선스 검증 → 1개 채택.
2. Day Master 아키타입 카피·카드 디자인(공유성 최우선) 프로토타입.
3. 차트→LLM 리딩 프롬프트 설계(톤·해석·grounding) + 토큰/비용 측정.
4. Flutter MVP: 온보딩→무료 리딩→공유카드→챗(3질문)→페이월.
5. 네이밍/브랜드(영어, "Saju" 검색성 + 차별). 출시 채널 = TikTok 오가닉.
