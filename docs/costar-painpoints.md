# Co-Star 페인포인트 → 우리 설계 원칙

> Co-Star(2천만 다운로드)의 공개된 사용자 불만을 분해해 **우리 K-사주 앱의 차별화 무기**로 전환.
> 출처: App Store/Reddit 리뷰, Vice·Dazed·Rolling Stone·Northeastern 윤리연구 등. 작성 2026-06-17.
> 상위 결정: [product-direction.md](./product-direction.md) · 제품 스펙: [mvp-global-ksaju.md](./mvp-global-ksaju.md).

## 핵심 통찰

Co-Star는 사용자가 **떠나는 이유**를 공개적으로 쌓아놨다. 그 약점 대부분이
**LLM + 결정론적 사주 차트**로 native하게 해결된다. 즉 Co-Star의 페인포인트 = 우리 기능 명세.

## 한 문장 포지셔닝 (도출)

> **"Co-Star가 차갑고 모호하게 던지는 걸, 우리는 따뜻하게·구체적으로·물어볼 수 있게 풀어준다 — 그리고 진짜 네 사주 차트에 근거해서."**

## 브랜드 톤 가드레일 (Co-Star 반면교사)

- 절대 사용자를 깎거나 겁주지 않는다(불안 유발 = 이탈 1위 요인).
- 추상적 미사여구 금지. 모든 문장은 차트 근거 + 실생활 적용으로.
- 모르는/불리한 운도 **대응책·격려**와 함께 전달.
- 용어는 항상 한 줄 설명을 붙인다(교육 = 리텐션).

## MVP 반영 체크

- [ ] 리딩 프롬프트에 톤 가드레일(따뜻·구체·지지) 명시 + 차트 grounding 강제.
- [ ] 자유 질문/후속 질문 가능한 챗 (Co-Star 약점 #3 정면).
- [ ] 모든 용어에 인라인 설명 토글.
- [ ] 무료 티어에 진짜 가치(데일리+카드) 보장, 페이월은 심화만.
- [ ] "결정론 차트 → LLM 해석" 아키텍처를 마케팅 포인트로(신뢰).
